## 19 Sep 2026 — Git/GitHub

**Learned:**

- `git init` → initializes Git in a project (it's create a local branch (master) into the folder)
- `git branch -M main` → renames this local current branch to main
- `git remote add origin <url>` → connects local repo to GitHub
- `git push -u origin main` → first push + sets upstream tracking
- `origin` → name/alias for the remote GitHub repository
- `-u` → sets upstream so future `git push` works without arguments (and current branch can have the track of git repo)
